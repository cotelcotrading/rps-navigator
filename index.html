    Model parameters

    RPSn = ROUNDDOWN[ (ES + NM + RE-OU + GEOP)n−1 × (Ko + Km)n ]
    Km(n) = Δpre × years from start to min(n, switch−1) + Δpost × years from switch to n   (n = CP year + 1)
    TER = ROUNDDOWN(created RECs + carry-over)  |  Shortfall = MAX(0, RPS − TER − opening bank)  |  Cost = Shortfall × price
    Holt: Lt = αyt + (1−α)(Lt−1+Tt−1), Tt = β(Lt−Lt−1) + (1−β)Tt−1, forecast = L + hT (floored at 0 for GEOP, NM, RE-OU, FIT)
